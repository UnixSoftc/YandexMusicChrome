# Yandex Music – расширение для Google Chrome

**Неофициальное расширение для браузера Google Chrome для прослушивания Яндекс Музыки.**

## Особенности
- Лёгкий и удобный плеер прямо в браузере  
- Работает в фоновом режиме, даже при закрытии вкладок  
- Регулировка громкости и перемотка треков  
- Плейлисты формируются из подборок: *Плейлист дня*, *Премьера*, *Дежавю*, а также раздела *Исследуйте жанры*  
- В дальнейшем функциональность будет расширяться  

## Установка и запуск
Для первого запуска требуется авторизация через токен Яндекса и предоставление разрешений.  

Версия: **0.3 (пилот)**

## Что нового в 0.3.0
Исправлены все известные баги из версии 0.1:
- **Play с первого раза.** Кнопка Play теперь запускает трек сразу после открытия плейлиста, а не только клик по названию.
- **Продолжение после паузы.** Состояние плеера (очередь, трек, позиция, громкость) хранится в `chrome.storage`, а не в памяти service worker. Если Chrome закрыл фоновый плеер после долгой паузы, трек продолжится с того же места.
- **Смена плейлиста.** Шапка и кнопки всегда показывают играющий трек, а список — открытый плейлист. Просмотр другого плейлиста музыку не прерывает; клик по треку заменяет очередь.

Заодно:
- Prev при >3 с от начала перезапускает трек, иначе переходит к предыдущему.
- Недоступные треки пропускаются; протухшая ссылка обновляется автоматически.
- Медиаклавиши и системный виджет Chrome (Media Session).
- Громкость запоминается; ползунок перемотки больше не «прыгает» при перетаскивании.
- Вход по OAuth больше не ломается, если ввод пароля занял больше 30 секунд.
- При недействительном токене показывается экран входа.
- Убраны неиспользуемые права (`activeTab`, `notifications`) и открытый доступ к шрифту; требуется Chrome 116+.

## Известные ограничения
- Выбор плейлистов зависит от неофициального API Яндекс Музыки и может сломаться при его изменении.
